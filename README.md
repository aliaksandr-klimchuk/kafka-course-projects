### Kafka Course Projects
Kafka Course Projects are a set of simple demo projects from 'Apache Kafka Crash Course for Java and Python Developers'
written to learn and understand the Kafka advanced features.



### How to start:
- Read HOW-TO-USE.pdf



### Technologies:
- Programming languages: Java;
- Frameworks: Spring Boot; 
- JMS: Apache Kafka;
- IDE: Visual Studio Code;
- Tools: Postman, Git, HTTPs, XML, YAML, JSON;
- Others: GitHub, ESLint.
